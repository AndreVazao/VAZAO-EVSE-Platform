## Critical symbol-to-package mismatch discovered (2026-10-16)

The CSV reports the pin numbers and functions declared by the current custom KiCad symbols, not verified physical package pin functions. A comparison against TI's official datasheets found a more serious defect than missing pins alone:

- `ADS131M06IPBSR` is the 32-pin TQFP (PBS) package, but the current symbol assigns AIN0P/AIN0N to physical pin numbers 1/2. TI's datasheet identifies pins 1/2 as AIN2P/AIN2N, pins 3/4 as AIN3N/AIN3P, and pins 5/6 as AIN4P/AIN4N. The symbol omits many physical pins.
- `TMCS1123A3AQDVGR` is modelled with only 8 pins although the official DVG package has 10; its pin 2 IN− is incorrectly typed as output instead of analog input.

Therefore this matrix must **not** be used to infer the physical ADC channel mapping, footprint pad mapping, or intended connectivity until both symbols are rebuilt and verified.
