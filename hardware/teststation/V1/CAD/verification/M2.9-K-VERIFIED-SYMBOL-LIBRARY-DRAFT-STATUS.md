## Datasheet-driven electrical-type correction — 2026-10-16

- Datasheet review confirmed physical pin 22 `XTAL2` of `ADS131M06IPBSR` must use KiCad electrical type `output`; TI identifies it as a digital output for crystal-oscillator excitation (Table 5-1): [TI ADS131M06 datasheet](https://www.ti.com/lit/ds/symlink/ads131m06.pdf).
- The first edit attempt (`976c65730db32c714c0e7bf3aad1fe12eca33bb6`) targeted pin 1 by mistake. The subsequent pin-block audit restored pin 1 `AIN2P` to `input` and set pin 22 `XTAL2` to `output` in `adb05513dd8b42016a668b0806dcbc9c8865f53c`.
- This is a symbol electrical-type correction only. It does not change the native schematic, any net, footprint, sensor polarity or circuit intent.
- Validation remains bounded: the committed text was checked to contain one pin-22 `XTAL2` block typed `output`; the Python regression script and KiCad CLI export workflow still have not been executed. Do not treat this as a KiCad parser pass.
