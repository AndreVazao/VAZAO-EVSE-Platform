## Required gates before schematic migration

1. Load/validate the library using the target KiCad version/CLI.
2. Compare each symbol to the manufacturer's package drawing and selected footprint pad numbering/orientation.
3. Verify the exact TMCS1123 order code.
4. Approve a complete pin-to-net intent matrix, including differential polarities, supply pins, unused pins, isolation domains and MCU interface assignments.
5. Migrate to a **new copy** of the native schematic; preserve the current M2.9-K master as evidence.
6. Re-export netlist, run ERC, review every changed connectivity item and obtain qualified electrical review before any fabrication or energization decision.
