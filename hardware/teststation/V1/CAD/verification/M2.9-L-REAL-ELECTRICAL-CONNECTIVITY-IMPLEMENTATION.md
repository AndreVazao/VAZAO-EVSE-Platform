# VAZAO EVSE TestStation V1 — M2.9-L Real Electrical Connectivity Implementation

## Status

Engineering implementation contract for the first electrically connected native KiCad schematic.

This milestone is intentionally conservative: the repository must contain a real native `.kicad_sch` with actual symbols, wires, labels and net connectivity. Text-only notes, placeholder geometry or hand-written pseudo-S-expressions do not satisfy this gate.

## Scope

Target source:

`hardware/teststation/V1/CAD/schematics/TS-V1-M2.9-K-MASTER.kicad_sch`

Required functional blocks:

- Zone A voltage measurement: L1/L2/L3
- Zone B voltage measurement: L1/L2/L3
- Zone A current measurement: L1/L2/L3
- Zone B current measurement: L1/L2/L3
- six isolated AMC1311B voltage channels
- six isolated 24 V → 5 V measurement supplies
- six TMCS1123 current channels
- two ADS131M06 ADCs
- dedicated ADC reference
- STM32G474 measurement controller
- STM32G031 EV/CP/PP controller
- ISO1044 isolated CAN
- CP/PP interface
- contactor drive/feedback
- emergency-stop/safety chain
- 24 V and 3.3 V power domains

- U6/U7/U8 = AMC1311BDWVR, Zone B L1/L2/L3 voltage
- U9/U10/U11 = MEE1S2405SC, Zone A isolated supplies
- U12/U13/U14 = MEE1S2405SC, Zone B isolated supplies

- U18/U19/U20 = TMCS1123A3AQDVGR, Zone B L1/L2/L3 current
- REF1 = ADC reference, exact MPN remains OPEN until selected and verified

### Control board

- U21 = STM32G474RET6
- U22 = STM32G031K8T6
- U23 = ISO1044BDWR

## Isolation rule

Every AMC1311B channel receives its own isolated 5 V supply.

- U9 → U3
- U10 → U4
- U11 → U5
- U12 → U6
- U13 → U7
- U14 → U8

No ISO_GND channel may be shared with another isolated voltage channel.

The native schematic must make these isolated domains visually and electrically unambiguous.

## Voltage measurement

Prototype divider baseline per channel:

- 4 × 470 kΩ series high-side resistance
- 10 kΩ low-side resistance

This remains a prototype baseline and must not be treated as final safety-rated mains design.

Each channel requires:

- HV input identification
- series/input protection as defined by the front-end review
- divider
- optional bandwidth/anti-alias network
- AMC1311B
- isolated 5 V supply
- isolated return
- differential ADC-side output

Final component values remain subject to voltage, transient, creepage, power and bandwidth verification.

## Current measurement

Each phase uses one TMCS1123A3AQDVGR channel.

The native schematic must show:

- current path
- sensor supply
- sensor ground
- VOUT
- VREF
- ALERT/OC where implemented
- ADC input conditioning
- explicit mapping to the corresponding ADC channel

No current channel may be left as an unconnected placeholder.

## ADC implementation

Each ADS131M06 must have:

- AVDD
- DVDD
- AGND
- DGND
- REFIN
- local decoupling
- SPI
- DRDY
- SYNC/RESET
- clock network according to the verified device configuration
- all unused/required pins handled according to the verified manufacturer documentation

The exact reference circuit and clock implementation are OPEN until the final symbol/datasheet review.

## MCU implementation

U21 STM32G474RET6:

- ADC-A SPI
- ADC-B SPI
- ADC DRDY inputs
- synchronization/control
- measurement processing
- safety-state supervision interface
- diagnostic interface
- CAN interface through U23

U22 STM32G031K8T6:

- CP generation/measurement
- PP identification

- contactor request/status interface
- fault-state interface

Physical MCU pin assignment must be verified against the selected package and firmware pin plan before ERC closure.

## CAN

U23 ISO1044BDWR separates the service/CAN domain from the measurement/control domain.

The native schematic must show:

- controller-side CAN TX/RX
- isolated-side CAN TX/RX
- isolated supply/return
- CANH
- CANL
- termination strategy
- ESD/transient protection where required

Termination is configuration-dependent and must not be hard-coded as permanently enabled unless the system architecture requires it.

## Safety chain

The native schematic must represent the safety path independently of normal software operation.

Required logical elements:

- emergency stop input
- safety contactor control
- contactor auxiliary feedback
- fault latch/state
- watchdog/supervision
- controlled de-energization

Software must not be the sole means of removing hazardous energy.

## Native schematic quality gate

M2.9-L is complete only when all of the following are true:

1. Native `.kicad_sch` exists.
2. All required designators exist.
3. Verified symbols are used.
4. Actual wires and labels create the intended nets.
5. ADC channels map exactly to the measurement contract.
6. Six isolated voltage domains remain independent.
7. Six current channels are electrically represented.
8. CP/PP paths are electrically represented.
9. Safety chain is electrically represented.
10. MCU communication paths are electrically represented.
11. ERC runs on the native schematic.
12. ERC findings are reviewed individually.
13. No ERC-clean result is accepted as proof of functional completeness by itself.
14. DRC is run only after verified PCB/netlist transfer.
15. No mains energization is authorized by this documentation milestone.

## Phase diagnostic preservation

The electrical connectivity must preserve independent acquisition for:

- Zone A phase angle
- Zone B phase angle
- L1-L2
- L2-L3
- L3-L1

The firmware can later calculate:

Δφ = φ_B − φ_A

and compare pre-EVSE and post-EVSE behavior.

Capacitor recommendations remain diagnostic engineering candidates only. They must never be generated solely from an arbitrary phase-angle threshold.
