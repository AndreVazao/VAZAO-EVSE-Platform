## Pin mapping baseline

### ADS131M06IPBSR
Functional channels remain:
- CH0: Zone voltage L1
- CH1: Zone voltage L2
- CH2: Zone voltage L3
- CH3: Zone current L1
- CH4: Zone current L2
- CH5: Zone current L3

The device provides six simultaneously sampled differential inputs and programmable phase-delay calibration. Exact physical pin numbers must be imported from the TI package drawing before netlist release.

### AMC1311BDWVR
Each isolated voltage channel:
- HV-side input: divider output
- HV-side return: divider return
- isolated low-side supply: +5 V_ISO
- isolated low-side return: GND_ISO
- low-side output: ADC differential input

The AMC1311B is a reinforced-isolation voltage-sensing amplifier with a 2 V input range and 3.3 V high-side operation. Independent isolated supplies remain mandatory for the six channels.

### TMCS1123A3AQDVGR
TI's DVG package pinout is:
1 IN+
2 IN-
3 GND
4 ALERT
5 VREF
6 VOUT
7 OC
8 VS
9 VOC
10 NC

For this prototype:
- IN+/IN- = phase conductor current path
- VOUT = ADC current channel
- VS = local 5 V/3.3 V supply as validated by final schematic
- ALERT/OC = safety/diagnostic inputs
- VREF = diagnostic/reference node
- VOC = programmed threshold or defined unused-state treatment
- NC = no functional connection unless manufacturer guidance requires otherwise

### STM32G474RET6
ST confirms LQFP64. Critical baseline pins include:
- VDDA / VSSA
- VREF+
- NRST
- SPI for ADS131M06
- CAN/service interfaces
- safety/watchdog GPIO
- contactor feedback/drive GPIO

Exact pin assignment is frozen only after the schematic sheet is created.

### STM32G031K8T6
ST confirms LQFP32. It is reserved for safety/EV interface control:
- CP PWM generation/measurement
- PP measurement
- contactor/driver control where allocated
- safety feedback
- service diagnostics

Exact pin assignment is frozen only after schematic/netlist creation.

### ISO1044BDWR
SOIC-8 isolated CAN transceiver:
- MCU-side TXD/RXD
- isolated CAN-side CANH/CANL
- VCC1/GND1
- VCC2/GND2

The two supply domains remain galvanically separated.

### MEE1S2405SC
Murata baseline:
- 24 V nominal input
- 21.6–26.4 V input range
- 5 V output
- 1 W maximum
- 200 mA maximum output
- 1000 V isolation
- SIP package

One isolated converter remains assigned to each AMC1311B isolated measurement channel.
