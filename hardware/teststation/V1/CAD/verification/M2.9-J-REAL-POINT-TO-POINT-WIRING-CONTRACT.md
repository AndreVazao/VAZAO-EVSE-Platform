## 1. Objective
M2.9-J converts M2.9-I into an explicit point-to-point net contract for the modern KiCad schematic. The legacy .sch remains bootstrap/documentation; this document is authoritative until native .kicad_sch generation and ERC.

## 2. Global domains
- 24V_SELV / 0V_SELV
- 3V3_CTRL / 3V3_MEAS
- AGND_A / DGND_A / AGND_B / DGND_B
- ISO5_A1..A3 and ISO5_B1..B3
- ISO_GND_A1..A3 and ISO_GND_B1..B3
- CP / PP / PE
- HV_ZONE_A / HV_ZONE_B

**Rule:** no isolated return may be shared between voltage channels.

## 3. ADC-A — U1 ADS131M06
- CH0 = A_L1_VP / A_L1_VN
- CH1 = A_L2_VP / A_L2_VN
- CH2 = A_L3_VP / A_L3_VN
- CH3 = A_L1_I / A_L1_I_RET
- CH4 = A_L2_I / A_L2_I_RET
- CH5 = A_L3_I / A_L3_I_RET
- AVDD/DVDD -> 3V3_MEAS
- AGND -> AGND_A; DGND -> DGND_A
- REFIN -> ADC_A_REFIN
- DRDY -> ADC_A_DRDY
- SYNC/RESET -> ADC_A_SYNC
- CS -> ADC_A_CS
- SCLK -> SPI_SCLK; DIN -> SPI_MOSI; DOUT -> SPI_MISO
- CLKIN/XTAL and CAP: final manufacturer implementation HOLD

## 4. ADC-B — U2 ADS131M06
- CH0 = B_L1_VP / B_L1_VN
- CH1 = B_L2_VP / B_L2_VN
- CH2 = B_L3_VP / B_L3_VN
- CH3 = B_L1_I / B_L1_I_RET
- CH4 = B_L2_I / B_L2_I_RET
- CH5 = B_L3_I / B_L3_I_RET
- power/control structure mirrors ADC-A with controlled reference and return routing

## 5. Six voltage channels
- U3 AMC1311-A1 -> ADC-A CH0
- U4 AMC1311-A2 -> ADC-A CH1
- U5 AMC1311-A3 -> ADC-A CH2
- U6 AMC1311-B1 -> ADC-B CH0
- U7 AMC1311-B2 -> ADC-B CH1
- U8 AMC1311-B3 -> ADC-B CH2

Each channel is: HV phase -> divider -> protection/filter -> AMC1311B -> ADC. Each AMC1311B receives its own isolated 5 V supply and isolated return.

## 6. Six current channels
Zone A:
- U15 TMCS1123-A1 -> ADC-A CH3
- U16 TMCS1123-A2 -> ADC-A CH4
- U17 TMCS1123-A3 -> ADC-A CH5
Zone B:
- U18 TMCS1123-B1 -> ADC-B CH3
- U19 TMCS1123-B2 -> ADC-B CH4
- U20 TMCS1123-B3 -> ADC-B CH5

Each sensor: VS -> 3V3_MEAS; GND -> local measurement ground; VOUT -> ADC; VREF -> controlled reference net; ALERT/OC -> MCU diagnostics/safety input. TI specifies 0.1 uF low-ESR local decoupling at VS. citeturn0search36

## 7. Six isolated supplies
- U9 MEE1S2405SC -> ISO5_A1 / ISO_GND_A1
- U10 MEE1S2405SC -> ISO5_A2 / ISO_GND_A2
- U11 MEE1S2405SC -> ISO5_A3 / ISO_GND_A3
- U12 MEE1S2405SC -> ISO5_B1 / ISO_GND_B1
- U13 MEE1S2405SC -> ISO5_B2 / ISO_GND_B2
- U14 MEE1S2405SC -> ISO5_B3 / ISO_GND_B3

Prototype local output baseline: 100 nF + 1 uF per isolated channel, subject to converter documentation verification.

## 8. MCU controllers
U21 STM32G474RET6: ADC SPI, CS, DRDY, SYNC, current diagnostics, safety status, CAN interface and service/debug.
U22 STM32G031K8T6: CP_PWM, CP_FB, PP_SENSE, contactor commands/feedback, ESTOP_OK and thermal/fan interface.
Exact physical STM32 pin assignment remains HOLD until verified manufacturer package symbols are loaded.

## 9. CAN / isolation
U23 ISO1044 provides the galvanic CAN barrier. CANH/CANL protection is placed only after cable, connector and transient environment are frozen. No protection component may unintentionally bridge the isolation barrier.

## 10. CP / PP
CP: connector -> protection -> feedback/level network -> U22 CP_FB; PWM: U22 -> protected driver -> CP.
PP: connector -> coding resistor bank -> protected ADC input -> U22 PP_SENSE.
Final resistor tolerances and clamp values remain controlled engineering items.

## 11. Contactor / safety
- K_MAIN_CMD -> driver -> K_MAIN
- K_MAIN auxiliary -> K_MAIN_FB
- K_LOAD_CMD -> driver -> K_LOAD
- K_LOAD auxiliary -> K_LOAD_FB
- physical E-stop -> independent energy removal
- MCU reads ESTOP_OK

Software must not be the sole means of preventing hazardous energy removal.

## 12. Net classes
| Class | Examples | Rule |
|---|---|---|
| HV | HV_ZONE_A/B | external industrial wiring / no PCB routing |
| ISO-HV-MEAS | divider to AMC | isolation and creepage controlled |
| ANALOG_DIFF | ADC inputs | short, matched, low-noise |
| ADC_REF | REFIN | dedicated precision routing |
| SENSOR_OUT | TMCS VOUT | short analog routing |
| DIGITAL | SPI | controlled edge/noise routing |
| SELV_POWER | 24V/3V3 | width by current/thermal calculation |
| CAN | CANH/CANL | paired routing |
| SAFETY | ESTOP/feedback | protected and segregated |
