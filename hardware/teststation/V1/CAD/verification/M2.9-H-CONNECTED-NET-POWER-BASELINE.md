# M2.9-H — Connected Electrical Net & Power Baseline

## Scope
This milestone extends M2.9-G from symbol placement into an explicit electrical connectivity contract. It defines the required net topology for the prototype before a KiCad ERC pass.

## 1. Measurement chain — Zone A

### Voltage
ZONE_A_L1_HV -> R divider A1 -> AMC1311B-A1 VINP/VINN -> isolated output -> ADC_A AIN0
ZONE_A_L2_HV -> R divider A2 -> AMC1311B-A2 -> ADC_A AIN1
ZONE_A_L3_HV -> R divider A3 -> AMC1311B-A3 -> ADC_A AIN2

### Current
ZONE_A_L1 conductor -> TMCS1123-A1 IN+/IN- -> VOUT -> ADC_A AIN3
ZONE_A_L2 conductor -> TMCS1123-A2 IN+/IN- -> VOUT -> ADC_A AIN4
ZONE_A_L3 conductor -> TMCS1123-A3 IN+/IN- -> VOUT -> ADC_A AIN5

## 2. Measurement chain — Zone B
Identical topology:
- B_L1_V -> AMC1311B-B1 -> ADC_B AIN0
- B_L2_V -> AMC1311B-B2 -> ADC_B AIN1
- B_L3_V -> AMC1311B-B3 -> ADC_B AIN2
- B_L1_I -> TMCS1123-B1 -> ADC_B AIN3
- B_L2_I -> TMCS1123-B2 -> ADC_B AIN4
- B_L3_I -> TMCS1123-B3 -> ADC_B AIN5

## 3. Isolated supply topology
Each AMC1311B channel receives its own isolated 5 V supply:
24V_SELV -> MEE1S2405SC -> ISO_5V_x / ISO_GND_x

No floating returns may be shared between isolated channels.

## 4. ADC power
Each ADS131M06 domain:
- AVDD/DVDD -> controlled 3.3 V measurement rail
- AGND/DGND -> measurement ground according to TI layout guidance
- REFIN -> dedicated precision reference network
- local high-frequency decoupling at supply pins
- SPI/DRDY/SYNC routed as a controlled digital group

## 5. Current-sensor supply
TMCS1123 channels:
- VS -> validated sensor supply
- GND -> measurement ground
- VOUT -> ADC input
- ALERT/OC/VOC remain explicit diagnostic/configuration nets

## 6. Control
STM32G474:
- SPI master -> ADC-A / ADC-B
- DRDY-A/B -> interrupt inputs
- SYNC/RESET -> ADC synchronization
- CAN_TX/RX -> ISO1044
- ESTOP_OK, K_MAIN_FB, K_LOAD_FB -> safety inputs
- SWD -> service connector

STM32G031:
- CP_PWM -> CP driver
- CP_FB -> ADC/comparator input
- PP_SENSE -> ADC
- ESTOP -> safety input
- K_MAIN_CMD / K_LOAD_CMD -> isolated/qualified drivers
- WATCHDOG -> independent supervision path

## 7. CAN isolation
STM32G474 -> ISO1044 MCU-side
ISO1044 isolated side -> CANH/CANL service bus

The isolation barrier must not be bridged by shields, debug grounds or accidental copper.

## 8. CP/PP
CP:
- PWM source
- series protection
- controlled output stage
- feedback measurement
- state detection

PP:
- resistor identification network
- protected ADC input
- no direct MCU pin exposure to the EV connector

## 9. Safety
E-STOP must remove hazardous energy independently of software.
Required feedback:
- K_MAIN auxiliary contact
- K_LOAD auxiliary contact
- supply monitor
- watchdog status

MCU state is diagnostic/control information and is not the sole safety function.

## 10. Decoupling/protection baseline
Every IC power entry receives local ceramic bypassing sized from the final manufacturer recommendations.
Protection to be explicit at:
- 24 V input
- CAN service interface
- CP/PP interface
- external service/debug connector
- sensor inputs where required

Exact values remain engineering selections until the final BOM and manufacturer recommendations are checked.

## 11. PCB transfer gate
Do not update PCB connectivity from this document alone.

Required sequence:
1. implement the nets in the KiCad schematic;
2. verify every pin;
3. annotate;
4. run ERC;
5. correct ERC findings;
6. update PCB from schematic;
7. assign verified footprints;
8. run DRC;
9. review isolation/creepage/thermal/current paths.

## Status
M2.9-H is a connectivity contract and engineering baseline. It is not an ERC-clean schematic, PCB release, Gerber package or mains-energization authorization.
