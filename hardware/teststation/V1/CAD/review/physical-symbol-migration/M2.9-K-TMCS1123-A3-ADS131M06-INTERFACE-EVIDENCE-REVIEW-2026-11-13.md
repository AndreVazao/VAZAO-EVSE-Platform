# M2.9-K — TMCS1123 A3 to ADS131M06 interface evidence review

Date: 2026-11-13  
Branch: `review/teststation-physical-symbol-migration`  
Status: **manufacturer evidence consolidated; no pin-to-net mapping approved**

## Purpose

Record what the official TI documentation establishes about the six `TMCS1123A3AQDVGR` current sensors (U15–U20) and the ADS131M06 ADCs (U1/U2), and explicitly separate transferable device facts from reference-design choices that cannot be copied into this circuit without review.

This document is an evidence register, not a wiring instruction. It does not authorize edits to the production master, the review schematic, a PCB, or any energized hardware.

## 1. Exact sensor variant and electrical operating envelope

The orderable part `TMCS1123A3AQDVGR` is listed by TI as ACTIVE, production, SOIC DVG, 10 pins. The A3 variant has:

- Fixed sensitivity: **75 mV/A**.
- Operating supply range: **3.0 V to 5.5 V**.
- At (V_S=5 V), listed linear current range: **−32 A to +32 A**.
- At (V_S=3.3 V), listed linear current range: **−32 A to +9.3 A**.
- A3 is an A-family variant: TI specifies a **2.5 V zero-current output reference** for all TMCS1123Axx variants.

Primary source: TI TMCS1123 datasheet SBOSA24D, revised May 2026: https://www.ti.com/lit/ds/symlink/tmcs1123.pdf  
Orderable part: https://www.ti.com/product/TMCS1123/part-details/TMCS1123A3AQDVGR

### Design implications

1. Do not assume that a 3.3 V sensor rail gives symmetric ±32 A range for this A3 variant. TI's table gives −32 A to +9.3 A at 3.3 V.
2. A 5 V supply is consistent with the A3 variant's symmetric ±32 A listed range, but the actual rail, tolerance, transient limits, sensor thermal design and system maximum current still require verification.
3. A3 uses the A-family **2.5 V** zero-current reference. Pin 5 VREF is the precision internal reference output.
4. The current project schematic's `*_I_RET` labels must not be treated as a sensor VREF connection merely because the legacy symbol placed a label on physical pin 5.

## 3. Reference-design comparison — TI TIDA-010937

TI's TIDA-010937 is a genuine TMCS1123 isolated Hall-current-sensing reference design. Its design guide states:

- It uses TMCS1123B1 for DC/AC noise tests and TMCS1123B3 for other tests.
- Those B variants provide a 1.65 V zero-current output at 3.3 V.
- The design routes VREF to an ADC negative input to form a pseudo-differential measurement.
- The reference design uses ADS7043 (SAR) and AMC1035 (delta-sigma modulator), not ADS131M06.
- Its 3.3 V rail supplies the sensor and ADC front-end; its supply/reference arrangement is specific to that design.

Sources:
- TI TIDA-010937 product/design-files page: https://www.ti.com/tool/TIDA-010937
- TI design guide TIDUF65, Section 3.1: https://www.ti.com/document-viewer/lit/html/TIDUF65/GUID-2BE7F651-9C30-4166-9050-B61D613FE533
- TI design guide TIDUF65, Section 3.2: https://www.ti.com/document-viewer/lit/html/TIDUF65/GUID-E3BD6673-6101-4215-A521-9DE8D466D3A2
- TI design guide TIDUF65, Section 3.3: https://www.ti.com/document-viewer/lit/html/TIDUF65/GUID-A34586C9-5353-43D1-B7C9-C400B0AD44FC

**Non-transferability warning:** the TIDA pseudo-differential VREF arrangement is not approved for this project. Its described sensor variants are B1/B3, while this project BOM names A3; the A3 device-comparison table lists no zero-current output voltage. Its ADCs are also not ADS131M06. Copying the reference schematic literally would therefore be unjustified.

## 4. ADS131M06 physical channel pin map

TI's ADS131M06 PBS 32-pin TQFP pin table identifies:

| ADC channel | Negative input | Positive input |
|---:|---:|---:|
| 0 | AIN0N pin 30 | AIN0P pin 29 |
| 1 | AIN1N pin 31 | AIN1P pin 32 |
| 2 | AIN2N pin 2 | AIN2P pin 1 |
| 3 | AIN3N pin 3 | AIN3P pin 4 |
| 4 | AIN4N pin 6 | AIN4P pin 5 |
| 5 | AIN5N pin 7 | AIN5P pin 8 |

Thus the existing functional grouping (U15–U17 → U1 channels 3–5; U18–U20 → U2 channels 3–5) is consistent only as a channel grouping note. It does **not** establish how each single-ended TMCS1123 VOUT signal is conditioned and presented to the ADC's differential inputs, nor which ADC polarity is intended.

TI describes the ADS131M06 as six simultaneously sampled differential inputs, with independently configurable channels and an integrated 1.2 V reference. Its own current-measurement example uses a split-burden current-transformer network; that circuit is not a TMCS1123 interface and must not be copied as one.

Sources:
- TI ADS131M06 datasheet SBAS949A, Section 5, Table 5-1: https://www.ti.com/document-viewer/ADS131M06/datasheet/GUID-5F789CD3-8B9C-470F-B37E-5D1F326C7DC4
- TI ADS131M06 datasheet, Section 9.2.2.2: https://www.ti.com/document-viewer/ADS131M06/datasheet/GUID-8E8004B3-46D1-4E72-91A9-789B473D2FEF

## 5. What is established versus still blocked

### Established by manufacturer evidence

- Exact sensor orderable part and 10-pin DVG identity.
- A3 sensitivity, 2.5 V zero-current reference, supply range and supply-dependent linear current range.
- TMCS1123 physical pin functions and unused-pin guidance.
- ADS131M06 PBS physical input pin numbers and N/P identities.
- TI reference design's B1/B3 VREF pseudo-differential implementation and its different ADC architecture.

### Still not approved

1. Whether A3 is the correct sensor sensitivity/range for the TestStation's actual maximum RMS, peak, fault and transient current.
2. Which isolated 5 V supply powers each sensor and the exact GND/return domain for each sensor and ADC.
3. Whether pin 5 VREF is routed as the ADC differential reference or used only for overcurrent threshold generation; this requires a reviewed input network. It is not a current return.
4. The VOUT conditioning network: divider/buffer/filter/protection and ADC common-mode/range compliance.
5. Whether the ADC channel uses a pseudo-differential reference, a buffered midpoint, or another approved analog front-end.
6. Exact N/P polarity for each sensor output at ADS131M06 channels 3–5.
7. Whether ALERT and OC are used for diagnostics/protection or intentionally tied off.
8. If OC is used, its threshold resistor/DAC design, threshold current, pull-up domain, and independent hardware shutdown behavior.
9. Input-current direction (IN+ to IN−), phase conductor routing, thermal design and system insulation constraints.

## 6. Required evidence before a corrected review schematic

- Confirm the intended operating current envelope for each phase and the selected A3 sensor range.
- Obtain the approved isolated-domain/supply allocation for U15–U20 and U1/U2.
- Design and review the analog VOUT-to-ADS131M06 front-end against both devices' absolute maximum, common-mode, differential input and filter requirements.
- Explicitly approve the differential polarity and channel assignment for all six sensors.
- Decide and document VOC, OC, ALERT, VREF and NC treatment per sensor.
- Only then populate approved destination nets in the machine-readable pin-to-net intent matrices.
- Make any wiring changes in a new review-only schematic copy; keep master and immutable baseline untouched.
- Regenerate KiCad XML netlist/ERC and compare every physical pin against the approved matrix.

No fabrication, EV connection or mains energization is approved by this document. System-level isolation, creepage/clearance, protective earth, overcurrent and emergency energy-removal architecture require qualified engineering review.


## Correction and superseding range audit — 2026-11-13

The earlier statement that A3 has no zero-current output voltage was incorrect. TI's Equation 14 states `TMCS1123Axx → VOUT,0A = VREF = 2.5 V`; pin 5 VREF is the internal precision zero-current reference output. The earlier caution against treating VREF as `*_I_RET` remains valid.

More importantly, the 32 A/phase project requirement is **32 A RMS**, whereas the sensor's linear range is an instantaneous/peak current range. A 32 A RMS sinusoid reaches 45.25 A peak. The selected A3 is only ±32 A at 5 V and −32 A to +9.3 A at 3.3 V, so it cannot linearly measure the stated nominal current waveform. See the superseding detailed calculation and variant comparison in `M2.9-K-CURRENT-CHANNEL-RANGE-AUDIT-2026-11-13.md`. A1 at 5 V and B1 at 3.3 V are comparison candidates only; neither has been selected.
