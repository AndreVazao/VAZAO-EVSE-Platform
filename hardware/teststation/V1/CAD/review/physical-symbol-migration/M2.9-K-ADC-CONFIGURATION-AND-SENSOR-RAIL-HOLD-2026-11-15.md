**Date:** 2026-11-15

**Branch:** `review/teststation-current-afe-design-study`

**Scope:** identify missing implementation inputs and contradictions that block final AFE/filter selection.

## 1. Executive result

The repository snapshot reviewed for PR #8 does not contain a verified ADS131M06 firmware register configuration or a confirmed ADC clock implementation. The current engineering contracts explicitly leave CLKIN/XTAL implementation on HOLD. Therefore the actual fCLKIN, fMOD, OSR, data rate, digital-filter mode, PGA register values and channel setup cannot currently be asserted from source evidence.

A second, more immediate design contradiction was found: the older M2.9-J point-to-point contract states TMCS1123 VS → 3V3_MEAS, while the new A1/THP210 study assumes a regulated 5 V TMCS1123 supply. This is not a cosmetic difference. The A1 ±70 A output calculation reaches 4.25 V at +70 A, which cannot be treated as compatible with a 3.3 V-powered sensor/output domain. The sensor rail must be explicitly reconciled against the selected sensor variant, linear range, output swing and downstream protection before the AFE is frozen.

These findings are recorded as HOLD items. No wiring or rail has been changed.

## 4. Sensor supply contradiction — blocking

### Existing contract

M2.9-J section 6 currently says:
- TMCS1123 VS → 3V3_MEAS;
- sensor GND → local measurement ground;
- VOUT → ADC;
- VREF → controlled reference net.

### New A1 study

The PR #8 A1 study assumes:
- TMCS1123A1 at regulated 5 V;
- nominal VREF = 2.5 V;
- nominal VOUT = 0.75–4.25 V at ±70 A;
- VOUT/VREF pair common-mode = 1.625–3.375 V;
- THP210 powered from +5 V.

The +70 A sensor output level is 4.25 V nominal (4.2675 V under the sensitivity-only +0.4% screen). This level exceeds a 3.3 V rail. Therefore the 3V3_MEAS sensor-supply instruction cannot silently coexist with the A1 ±70 A / 5 V transfer study.

### Required closure

Before any schematic or net change:
1. Confirm the exact TMCS1123 orderable variant for the six channels.
2. Decide and document the sensor VS rail per channel (3.3 V or 5 V) with regulator tolerance, ripple, startup and brownout behaviour.
3. Recalculate the exact sensor output range/linear range at that rail and temperature.
4. Confirm VOUT/VREF absolute limits and output loading under all expected currents.
5. Confirm the selected input conditioning tolerates the sensor-side common-mode and fault voltages while protecting the 3.3 V ADC domain.
6. Reconcile M2.9-J, M2.9-L, BOM and the AFE study in a separately reviewed change only after the evidence is complete.

No assumption is made here that 5 V is approved; it is the supply used by the current A1 study candidate and must be checked against the power tree, isolation domains and actual design.

## 5. Additional architecture records to reconcile

The source documents also differ in how the ADC reference is described:
- M2.2 records the ADS131M06 internal reference as the initial prototype baseline.
- M2.9-J and M2.9-L describe a dedicated ADC reference / REFIN network.
- The AFE study does not select the reference implementation.

This must be resolved from the actual ADC reference pin wiring, BOM and register configuration. Do not infer that REFIN is externally driven merely because the contract names an ADC_A_REFIN net.

The current-channel architecture also needs a consistent statement of measurement ground and sensor supply domains for U15–U20. The functional channel grouping (U15–U17 to ADC-A channels 3–5; U18–U20 to ADC-B channels 3–5) does not approve pin polarity, sensor rail, reference wiring or analog ground destinations.

## 6. Engineering hold points

The following are hard blockers before a design can be selected:
- [ ] Firmware/source evidence for actual ADC clock, OSR, data rate, filter and PGA.
- [ ] Sensor VS rail resolved against the 3V3_MEAS contract and A1 5 V study.
- [ ] ADC reference implementation resolved (internal vs external REFIN).
- [ ] Exact ADS131M06 channel configuration and input pair mapping verified from the corrected physical symbol and datasheet.
- [ ] THP210 closed-loop input differential checked against ±0.5 V absolute maximum.
- [ ] Sensor-powered / FDA-unpowered, rail collapse, clamp current and startup cases simulated.
- [ ] ADC input impedance and THP210 stability/settling evaluated at the real fMOD/OSR.
- [ ] Filter gain/phase, alias rejection and six-channel matching evaluated at required 50/60 Hz harmonics.
- [ ] Complete sensor + FDA + passive + ADC error budget closed.
