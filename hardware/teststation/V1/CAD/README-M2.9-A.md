# M2.9-A — KiCad source bootstrap

This directory contains the first real KiCad PCB source containers for TestStation V1.

Files:
- TS-V1-M2.9-A.kicad_pro — project metadata bootstrap.
- PCB-A/TS-V1-PCB-A.kicad_pcb — 160 x 100 mm PCB-A board source.
- PCB-B/TS-V1-PCB-B.kicad_pcb — 120 x 80 mm PCB-B board source.
- PCB-C/TS-V1-PCB-C.kicad_pcb — 120 x 80 mm PCB-C board source.

Status:
- Real KiCad PCB syntax and board outlines are committed.
- Mounting-hole/mechanical baseline is committed.
- Component placement, routing, verified footprints, schematic hierarchy, ERC/DRC and fabrication outputs are NOT yet claimed complete.
- No mains energization is authorized.

This is intentionally an incremental M2.9-A source bootstrap rather than a fabricated or production-ready release.
